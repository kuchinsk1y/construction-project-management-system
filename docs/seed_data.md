# Seed Data (Демонстрационные данные)

В проекте настроен механизм автоматического заполнения базы данных тестовыми (демонстрационными) данными для удобства разработки и тестирования. За это отвечает скрипт `api/prisma/seed.ts`. 

Скрипт использует логику `upsert` (обновить или вставить), поэтому его можно безопасно запускать несколько раз подряд — данные не будут дублироваться.
